# Netflix Content Catalog & Release Trend Dashboard

A Python and Flask web application that analyzes Netflix's movie and TV catalog (`netflix_titles.csv`) using pandas and generates visual reports with Matplotlib.

## Features
- **Top 10 Genres:** Bar chart and tabular breakdown of the most frequent content categories.
- **Content Ratings:** Distribution across TV and movie maturity ratings.
- **Release Trends:** Multi-year release volume line chart, plus interactive filtering by genre.

## Tech Stack
- Python, Flask, pandas, Matplotlib, HTML/CSS (Jinja2)
